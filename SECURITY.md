# Security Policy

MoTorch is an early-stage, pre-alpha research library. Its interfaces and supported-version policy may change as the project develops.

## Supported versions

Only the latest version on the default branch is currently considered for security fixes. No released version is yet covered by a long-term support commitment.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting feature for this repository when it is available. Provide a clear description, affected version or commit, reproduction details, and the potential impact.

Do not publish active or suspected vulnerabilities in public GitHub issues. Maintainers will assess valid reports, coordinate a fix where practical, and communicate disclosure timing through the private report.
